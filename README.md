# Cyber Taxi Arcade


A small retro-style arcade driving game inspired by the simple car games from old-school handheld consoles.

I grew up playing one of those “99-in-1” handheld games where the graphics were basically just tiny blocks arranged to look like cars, roads, and other objects. One of the games I enjoyed was a simple car-dodging game, and that became the inspiration for Cyber Taxi Arcade.

The idea is simple: dodge traffic, collect power-ups, survive as long as you can, and beat your high score.

✨ Features
🚕 3-lane arcade gameplay — Move left and right to dodge incoming cars.
📈 Progressive difficulty — The game gradually gets faster as your score increases.
🛡️ Shield power-up — Absorb one collision without ending the run.
🚀 Turbo boost — Temporarily increases your speed and score gain.


🎮 How to Play
Start the game with INSERT COIN.
Move between the three lanes to avoid incoming cars.
Collect Shield and Turbo power-ups.
Keep driving as long as possible.
Try to get the highest score you can.

That's it. No complicated mechanics — just a tiny arcade game with a bit of nostalgia behind it.

📌 Project

Cyber Taxi Arcade is a small experiment in building a playable browser game using vanilla web technologies, without a game engine or external game framework.

The goal was to keep the implementation simple while still giving the game a distinct visual style, responsive controls, audio feedback, and a little bit of arcade personality.
